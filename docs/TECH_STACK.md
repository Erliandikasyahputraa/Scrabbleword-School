# Technology Stack

## Laravel
Chosen for its robust ORM, routing, and ecosystem. PHP runs natively on 99% of shared hosting providers, ensuring cheap deployment.

## React & TypeScript
Provides a component-based, highly interactive user interface. TypeScript ensures type safety across API boundaries.

## Tailwind CSS
Utility-first CSS framework that drastically speeds up UI development without custom CSS bloat.

## Sanctum
Lightweight authentication tailored for SPAs and simple APIs. Avoids the complexity of Passport (OAuth2).

## MySQL
Standard relational database, universally supported by free hosting providers (InfinityFree).

## Vercel
World-class edge network for deploying static frontend assets for free.

## InfinityFree
Zero-cost shared hosting for PHP/MySQL, acting as a proving ground for the backend architecture.
